# EXP006 mapping to the Francioni experiment

Status: **DESIGN DOCUMENT**

## Features represented directly

| Francioni feature | EXP006 abstraction |
|---|---|
| Four or five P+ and P- controlling cells | Primary `N=10`, secondary `N=8`, balanced hidden roles |
| Mean P+ minus mean P- controls a grating | Identical normalized opponent contrast controls a bounded visual state |
| Seven displayed orientations | Seven visual-state bins from 0 to 90 degrees |
| Up to 28 seconds to reach target | Up to 28 one-second action frames |
| Reward one second after success | One non-action reward-delay frame |
| Continuous visual feedback | Current and previous visual bins available at every action frame |
| Role-dependent soma--dendrite residual | Common simulated soma/dendrite layer and identical residual analysis |
| Learning across repeated sessions | Fourteen 64-trial acquisition blocks and fourteen remap blocks |

## Deliberate abstractions

EXP006 does not simulate retrosplenial anatomy, calcium kinetics, locomotion,
vascular or neuropil artifacts, dendritic cable dynamics, or the complete training
history of an animal. One action frame represents one second rather than the 15 Hz
imaging stream. The common observation layer is an explicit measurement model, not
a claim that calcium is generated by a linear equation.

The biological experiment did not directly measure synaptic weights and did not
establish that its residual was a gradient. Its residual tracked changes in task
error and could reflect teaching, online control, or another dendritic computation.
EXP006 therefore compares explanatory sufficiency. It does not label every
role-dependent signal as backpropagation.

## Critical improvement over EXP005

EXP005 supplied only short closed-loop action sequences followed by a delayed
scalar outcome. EXP006 additionally supplies continuous visual state and visible
state change. This prevents failure caused merely by withholding information that
was available to the animals.

## Critical remaining limitation

The synthetic dendritic residual depends on a common observation model. A positive
result shows that a learner's internal signal could survive that transformation. A
negative result could arise in the learning mechanism, in the chosen mapping from
internal signal to dendrite, or in both. Latent and measured endpoints are therefore
reported side by side.
