# EXP004 theory analysis: origin of neuron-specific topology

Status: written before any EXP004 simulation. This analysis concerns the frozen EXP003b source at checkpoint `0e68fedbd7f35d223234b07d9e96f958d7b2896c`; it does not alter EXP003b Outcome C.

## Question and object separation

EXP004 asks where the coordinates of a learned top-down expectation come from. The relevant frozen objects are:

| Object | Frozen EXP003b implementation | Plastic? | Information role |
|---|---|---:|---|
| \(B_h\) | `controller.motor_basis[h]`, an antithetic random population-action bank | No in the primary condition | Constrains the actions and soma patterns that can be generated behaviorally. |
| \(P_k\) | complement-coded fuzzy-ART prototype in `controller.prototypes[k]` | Yes | Partitions observable context/task states; determines which value and T memory slot receives each sample. |
| \(V_{k,h}\) | `controller.values[k,h]` | Yes | Scalar structural-credit state controlling later hypothesis selection and motivated gain. |
| \(T_{k,h}\) | `controller.topdown[k,h,:]` | Yes | Category–hypothesis-specific learned population expectation. It does not alter \(B_h\) in the clean test. |
| \(S_t\) | experienced lower `soma`; outstar target is \(S_t-\bar S_t\) | Generated by fixed \(B_h\), lower circuit, and current task state | Supplies the neuron coordinates that a local outstar update can store. |

The clean EXP004 primary removes SMART/lower plasticity, so \(S_t\) is generated only by the fixed action repertoire and environment. That isolates assumption A2 from the later cellular transform.

## Exact frozen EXP003b value and outstar updates

Let trace items be processed in reverse temporal order, with \(j=0\) the most recent action frame. With \(d\) distractors and three action frames,

\[
w_j = \rho_{WM}^{d}\rho_e^j,
\]

where frozen \(\rho_{WM}=0.90\), \(d=4\), and eligibility decay \(\rho_e=0.82\). Thus \(\rho_{WM}^d=0.6561\).

The scalar outcome is

\[
o_t=0.8\,\mathrm{global\ improvement}+0.2\,\mathrm{reward}.
\]

Because `global_improvement = 1 - final_error = final_state` and the state and reward are clipped/binary in \([0,1]\), \(o_t\in[0,1]\).

For a structurally credited pair \((k,h)\), the frozen code first updates its value:

\[
V^+_{k,h}=V_{k,h}+\alpha_V w_j(o_t-V_{k,h}),
\qquad \alpha_V=0.24.
\]

It then computes motivated source gain from the **updated** value:

\[
g_{k,h}=
\begin{cases}
1+\max(0,V^+_{k,h}),&\text{motivated attention enabled},\\
1,&\text{otherwise},
\end{cases}
\]

and updates the top-down expectation toward the mean-centered soma target

\[
X_t=S_t-\bar S_t
\]

using

\[
T^+_{k,h}=T_{k,h}+\eta_{eff,j}(X_t-T_{k,h}),
\]

with exact effective rate

\[
\boxed{\eta_{eff,j}=\alpha_T\,g_{k,h}\,w_j},
\qquad \alpha_T=0.09.
\]

The update is resonance-gated unless the corresponding ablation disables that gate.

## Bounds on the effective rate

Values start at zero. Since \(\alpha_Vw_j\le0.24<1\) and outcomes lie in \([0,1]\), the value update is a convex interpolation and preserves \(V_{k,h}\in[0,1]\). Consequently \(g_{k,h}\in[1,2]\).

For any frozen primary trace item,

\[
0\le\eta_{eff,j}\le 0.09\times2\times0.6561=0.118098<1.
\]

Even if the delay attenuation were absent, the implementation-level bound would be \(0.18<1\). Therefore every actual primary outstar update is a convex interpolation. Motivated attention can increase a target's scalar coefficient but cannot directly add a cell-specific vector.

## Exact reachability expansion

For one \((k,h)\) updated at ordered times \(1,\ldots,n\), let \(\eta_m\) be its recorded effective rate and \(X_m\) its recorded target. Repeated substitution gives

\[
T_n=
\left[\prod_{\ell=1}^{n}(1-\eta_\ell)\right]T_0
+\sum_{m=1}^{n}
\left[\eta_m\prod_{\ell=m+1}^{n}(1-\eta_\ell)\right]X_m.
\]

All coefficients are nonnegative and sum to one. Therefore:

- \(T_n\) lies in the convex hull of \(T_0\) and the targets actually sampled for that pair;
- it lies in their affine hull and in the linear span of \(\{T_0,X_1,\ldots,X_n\}\);
- it need not lie in the span of targets alone because frozen EXP003b initializes \(T_0\) to a small random mean-centered vector rather than zero;
- value and motivated-attention terms change only the scalar convex weights while the rate remains in \([0,1]\); they cannot move T outside that hull.

EXP004 will initialize T to zero in the clean primary model. This removes the small random coordinate prior and makes every learned T reconstructible from experienced targets alone.

## How scalar outcome legitimately supplies causal information

The convex-hull constraint does **not** imply that “T is only an average and learns no information.” The target distribution is policy-dependent:

```text
hidden causal mapping
  -> consequences of each B_h-generated soma pattern
  -> visible task improvement and scalar outcome
  -> V(k,h) and later hypothesis/category selection
  -> successful trajectory occupancy
  -> which soma targets repeatedly update each T(k,h)
  -> outcome-weighted outstar representation
```

Reward therefore affects T through two legitimate non-cell-indexed channels:

1. **sampling:** V changes future selection, so a T associated with a successful H receives a different distribution of soma targets;
2. **scalar integration weight:** updated positive V increases \(g_{k,h}\), making those targets count more strongly.

Breaking the outcome–selection relationship while preserving target marginals is the appropriate counterfactual test. A useful fixed repertoire and genuine scalar-outcome information acquisition can both be necessary.

## What ART category learning constructs

For complement-coded observation \(I_t\), frozen category recruitment stores \(P_{new}=I_t\). A resonant existing prototype changes by

\[
P_k^+=P_k+\beta\,[\min(I_t,P_k)-P_k],
\qquad \beta=0.12.
\]

This componentwise fuzzy-intersection update is genuine representational learning. Vigilance failure rejects candidates; reset/search can recruit a new category. Each category owns separate \(V_{k,h}\) and \(T_{k,h}\) memories.

Category formation therefore controls:

- which observable context/state observations are grouped;
- which samples compete for the same value state;
- which hypotheses a category comes to favor;
- which soma targets are integrated into each T;
- whether the same h can own different T patterns in different learned categories.

A **new category** creates a new learned memory slot and can factor contexts or task states. It does not create a new motor vector \(B_h\). Prototype modification can denoise/generalize task state while motor output remains repertoire-limited.

## Five distinct forms of construction

| Process | What changes? | Is it genuine learning? | Does it create a new motor vector? |
|---|---|---:|---:|
| A. New vector values in T | Convex coefficients combine T0 and experienced population targets | Yes | No |
| B. New ART category | A new prototype plus new V/T memory slots | Yes | No |
| C. Selection/reweighting | V changes which fixed B_h is chosen and how often its targets are sampled | Yes | No |
| D. Causal discovery through scalar outcome | Hidden mapping changes consequences, which changes selection and target occupancy | Yes | No |
| E. Structure outside permitted operations | A direction not reconstructible from T0 and recorded targets, or a changed B_h | Not in the clean architecture; initially indicates a bug or hidden mechanism | Potentially |

“Fixed motor repertoire” must not be described as “fixed lookup-table ART.” The actions are fixed, but categories, prototypes, values, policy, target distribution, and top-down memories remain plastic.

## Behavioral versus representational expressivity

### Behavioral expressivity

At each action frame the clean model emits one fixed \(B_h\). It can behaviorally realize:

- one repeated pattern;
- a sequence \((h_1,\ldots,h_F)\) across closed-loop frames;
- different sequences in different learned categories/states/contexts.

It cannot emit an arbitrary simultaneous convex mixture unless such mixing is explicitly implemented. Accordingly, the primary behavioral oracle must enumerate allowed closed-loop sequences. A convex-mixture oracle is only a mathematical upper bound.

### Representational expressivity

T can be a vector not equal to any B or any single soma target. Category-conditioned, outcome-biased convex integration can denoise nuisance variation and make T more correlated with the hidden role than every individual sampled target. That is **ART/outstar representational construction**, provided exact replay of the recorded update history reconstructs it.

Such improvement does not create a new action. It is a new learned representation of outcome-selected experiences over a fixed action repertoire.

## Predictions to be tested

1. If frozen EXP003b was dominated by lucky repertoire selection, initial best causal score/alignment will strongly predict final behavior, selected H, and final T alignment.
2. If scalar outcome supplies additional information, shuffling outcome labels or reinforcement assignment while preserving exposure will destroy T-role alignment.
3. If ART categories construct useful factorization beyond a contextual bandit, recruitment/modification will explain variance after controlling for initial coverage and will create distinct T for the same h.
4. If outstar integration is constructive, final T can exceed every single target while remaining exactly reconstructible from recorded targets and rates.
5. If the repertoire is the bottleneck, controlled low-single-coverage banks will fail despite a strong allowed-sequence oracle, and coverage will mediate bank-size effects.

## Claim boundary

EXP004 can determine whether A2 is supported in a weak, repertoire-dependent form and whether category/outstar learning creates a new representation. It cannot show that a new motor direction is created in the primary condition, reproduce the Francioni dendritic residual, validate SMART, or establish a biological cellular-credit rule.
