# Manuscript

This directory contains the editable LaTeX manuscript, its BibTeX database, and
the compiled PDF for the `part-vector-credit` research program.

## Build

From this directory, run:

```bash
tectonic part_vector_credit_manuscript.tex
```

The command regenerates `part_vector_credit_manuscript.pdf`. LaTeX intermediate
files are excluded from version control by the repository `.gitignore`.

## Evidence boundary

The manuscript synthesizes the archived protocols, frozen analyses, held-out
experiment records, and explicitly labeled post-hoc audits in this repository. It
does not add new simulation results.
